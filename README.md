## 1. Descrição

<br />


O **Projeto Livraria** é um sistema de gestão projetado para simular e administrar venda e inserção de livros para um e-commerce. Oferece funcionalidades como **cadastro**, **consulta**,**quantidade de livros disponíveis**, **atualização** e **remoção** de livros quando finalizado o estoque

O sistema organiza as informações dos livros — incluindo nome do titulo, número de cadastro, se disponível ou esgotado na unidade — garantindo a realização segura das vendas. Seu principal objetivo é automatizar e simplificar o gerenciamento de vendas, com a facilidade de verificação, promovendo agilidade e precisão no controle de estoque.

Este projeto, desenvolvido em **Java**, foca no estudo e aplicação dos conceitos de **Programação Orientada a Objetos (POO)**, incluindo:

- Classes e Objetos;
- Atributos e Métodos;
- Modificadores de Acesso;
- Herança e Polimorfismo;
- Classes Abstratas;
- Interfaces.

Além de servir como um simulador funcional, o projeto oferece uma base prática para compreender os princípios fundamentais da POO aplicados a um cenário realista.

<br />

## 2. Funcionalidades do Projeto

<br />

1. **Cadastrar livro:** Cria um estoque especificando nome do livro, número de cadastro, prateleira alocada e quantidade de unidades disponíveis. O número de conta é gerado automaticamente.
2. **Listar todos os livros:** Lista todos os livros cadastradas no sistema.
3. **Buscar livro:** Encontra um livro e informa a quantidade disponível.
4. **Atualizar quantidade** Permite atualizar o quantitativo de um livro já cadastrado a partir do número de cadastro.
5. **Vendido (excluir):** Remove um livro específico com base no número de cadastro.
